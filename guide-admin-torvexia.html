Démarrage du site et accès à l'administration

Comment lancer le serveur local et accéder au panneau admin

1.1 — Lancer le serveur de développement

Le site fonctionne en local sur votre ordinateur. Avant de pouvoir le consulter ou accéder à l'admin, vous devez démarrer le serveur.

Ouvrez le terminal PowerShell dans le dossier du projet. Le dossier du projet se trouve ici :
C:\Users\HP\torvexia-global
Tapez la commande suivante et appuyez sur Entrée :
npm run dev
Attendez le message de confirmation : vous verrez Ready in X ms. Le site est maintenant accessible.
⚡
Important

Le serveur doit rester ouvert dans le terminal pendant que vous travaillez. Ne fermez pas la fenêtre PowerShell pendant l'utilisation du site.

1.2 — Accéder au panneau d'administration

Une fois le serveur lancé, ouvrez votre navigateur (Chrome recommandé) et allez à cette adresse :

localhost:3000/admin/login
Entrez votre mot de passe dans le champ prévu (voir ci-dessous).
Cliquez sur "Se connecter". Vous serez redirigé vers le tableau de bord.

Mot de passe par défaut

Mot de passe : torvexia2024

1.3 — Changer le mot de passe

Pour changer le mot de passe, ouvrez le fichier .env.local à la racine du projet :

C:\Users\HP\torvexia-global\.env.local
ADMIN_PASSWORD=votre_nouveau_mot_de_passe

Sauvegardez le fichier et redémarrez le serveur (Ctrl+C puis npm run dev).

🔒
Sécurité

Changez le mot de passe par défaut avant de mettre le site en ligne. N'utilisez jamais torvexia2024 en production.

1.4 — Se déconnecter

Dans la sidebar de gauche, cliquez sur "Déconnexion" en bas. Vous pouvez aussi aller directement à localhost:3000/admin/logout.

URLDescription

localhost:3000/enSite en anglais

Médiathèque — Gérer photos et vidéos

Téléverser, organiser et supprimer vos fichiers médias

3.1 — Téléverser des fichiers (Upload)

Accédez à Médiathèque dans la sidebar.

Choisissez la catégorie de destination en cliquant sur un des boutons en haut de la zone d'upload : Général Tracteurs Équipements Logos Vidéos
Déposez vos fichiers directement sur la zone pointillée (glisser-déposer) OU cliquez sur la zone pour ouvrir le sélecteur de fichiers.
Attendez la progression : chaque fichier affiche une icône de chargement. Une fois terminé, la miniature apparaît instantanément dans la grille.

Formats acceptés

TypeFormatsTaille max
ImagesJPG, PNG, WebP, GIF100 MB
VidéosMP4, WebM, MOV (QuickTime)100 MB
💡
Upload multiple

Vous pouvez sélectionner ou glisser plusieurs fichiers en même temps. Ils seront uploadés en parallèle.

3.2 — Filtrer et parcourir

Sous la zone d'upload, trois boutons permettent de filtrer l'affichage :

  • Tous — affiche tous les fichiers
  • Images — affiche uniquement les photos
  • Vidéos — affiche uniquement les vidéos

Le chiffre entre parenthèses indique le nombre de fichiers dans chaque catégorie.

3.3 — Voir les détails d'un fichier

Cliquez sur une miniature pour ouvrir le panneau de détails à droite. Il affiche :

  • Un aperçu agrandi (image ou lecteur vidéo)
  • Le type, la taille, la catégorie et la date d'ajout
  • Bouton "Copier l'URL" — copie le lien direct du fichier dans votre presse-papiers
  • Bouton "Supprimer" — supprime définitivement le fichier

3.4 — Supprimer un fichier

Survolez la miniature pour voir apparaître l'icône ✕ en haut à droite.
Cliquez sur ✕ ou utilisez le bouton "Supprimer" dans le panneau de détails.
Confirmez la suppression dans la boîte de dialogue.
⚠️
Suppression définitive

La suppression efface le fichier du serveur et de la base de données. Cette action est irréversible. Assurez-vous de ne plus utiliser l'image avant de la supprimer.

3.5 — Où sont stockés les fichiers ?

Tous les fichiers uploadés sont enregistrés dans le dossier :

C:\Users\HP\torvexia-global\public\uploads\

Chaque catégorie a son propre sous-dossier : tractors/, implements/, general/, logos/, videos/.

Galeries — Organiser vos collections

Créer des groupes d'images thématiques

Les galeries permettent de regrouper des images de la médiathèque en collections organisées (ex : "Tracteurs TX504", "Machines en action", "Démos client").

💡
Pré-requis

Vous devez d'abord ajouter des images dans la Médiathèque avant de pouvoir les intégrer à une galerie.

4.1 — Créer une nouvelle galerie

Cliquez sur "Nouvelle galerie" (bouton amber en haut de la page).
Donnez un nom à la galerie (obligatoire), ex : "Tracteurs TX704 — Inspection 2026".
Ajoutez une description (optionnel) pour vous y retrouver plus facilement.
Sélectionnez les images dans la grille : cliquez sur chaque image à inclure. Une coche apparaît sur les images sélectionnées.
Cliquez sur "Enregistrer". La galerie apparaît dans la liste.

4.2 — Modifier une galerie

Trouvez la galerie dans la liste et cliquez sur "Modifier".
Modifiez le nom, la description ou la sélection d'images.
Cliquez sur "Enregistrer" pour appliquer les changements.

4.3 — Supprimer une galerie

Cliquez sur le bouton rouge "Supprimer" sur la carte de la galerie, puis confirmez. Note : supprimer une galerie ne supprime pas les images de la médiathèque — elles restent disponibles.

4.4 — Aperçu d'une galerie

Chaque galerie affiche une grille de 4 miniatures (les 4 premières images sélectionnées) ainsi que le nombre total d'images.

4.5 — Utiliser une galerie sur le site

Pour afficher une galerie sur votre site, vous pouvez utiliser les URLs directes des images. Chaque image a une URL de type :

http://localhost:3000/uploads/tractors/nom-du-fichier.jpg

Copiez l'URL depuis le panneau de détails dans la Médiathèque et utilisez-la dans les sections du catalogue ou de présentation.

Modifier le logo et l'identité visuelle

Changer le logo, les couleurs et la typographie du site

6.1 — Logo actuel (lettre "T")

Le logo actuel est un carré amber avec la lettre T. Il apparaît dans la navbar en haut, dans le footer, et sur la page de connexion admin. Pour modifier cette lettre ou sa couleur :

Modifier dans la Navbar

src\components\layout\Navbar.tsx — ligne ~62
// Changez la lettre "T" par votre initiale <div className="w-8 h-8 bg-amber-500 rounded-lg..."> T ← modifier ici </div>

Modifier dans le Footer

src\components\layout\Footer.tsx — ligne ~30

6.2 — Remplacer par un vrai logo image

Pour utiliser un fichier image (PNG transparent recommandé) comme logo :

Uploadez votre logo dans la Médiathèque (catégorie "Logos"). Copiez son URL.
Dans Navbar.tsx, remplacez le bloc <div>T</div> par :
<img src="/uploads/logos/votre-logo.png" alt="TORVEXIA" className="h-8 w-auto" />
Faites la même modification dans Footer.tsx et dans src/app/admin/login/page.tsx.

6.3 — Changer les couleurs du site

La couleur principale est le amber (doré). Elle est utilisée dans tout le site via les classes Tailwind amber-400, amber-500. Pour changer la couleur d'accentuation :

🎨
Remplacement global des couleurs

Utilisez la fonction "Remplacer dans tous les fichiers" de votre éditeur de texte (VS Code : Ctrl+Shift+H) pour remplacer amber par une autre couleur Tailwind comme orange, yellow, emerald, ou sky.

6.4 — Modifier le nom "TORVEXIA"

Le nom de marque est affiché directement dans les composants. Pour le changer, recherchez TORVEXIA dans tous les fichiers du dossier src/ et remplacez-le par votre nom de marque.

6.5 — Typographie

Le site utilise deux polices Google Fonts :

PoliceUsageVariable CSS
Space GroteskTitres, prix, nombres--font-display
InterCorps de texte, navigation--font-sans

Pour changer les polices, modifiez le fichier src/app/[locale]/layout.tsx — remplacez les imports de Space_Grotesk et Inter par d'autres polices Google Fonts.

💡

7.2 — Structure du fichier

Chaque fichier est organisé par section du site. Exemple pour modifier le titre de la section Paiement en français :

// messages/fr.json — extrait { "payment": { "title": "Paiement 100% Sécurisé", ← modifier ici "subtitle": "Système de paiement par étapes...", "badge": "Investissement protégé" } }

7.4 — Modifier un témoignage client

Les textes des 12 témoignages sont dans la clé testimonials.items. Pour modifier le texte du 3ème témoignage en anglais :

// messages/en.json "testimonials": { "items": [ { ... }, // témoignage 1 { ... }, // témoignage 2 { "text": "Votre nouveau texte ici...", "role": "Votre titre, Ville" }, // témoignage 3 ← modifier ... ] }
⚠️
Syntaxe JSON

Faites attention aux virgules et guillemets doubles. Si le fichier JSON est invalide, le site affichera une erreur. En cas de doute, utilisez jsonlint.com pour vérifier votre JSON avant de sauvegarder.

Gérer les témoignages clients

Ajouter de nouveaux avis, modifier les noms et notes

Les témoignages sont gérés en deux parties : les données fixes (nom, pays, produit, étoiles) dans le fichier composant, et les textes traduits dans les fichiers de langue.

9.1 — Modifier ou ajouter un témoignage

Étape 1 — Données fixes du client

Ouvrez le fichier :

src\components\sections\TestimonialsSection.tsx

Trouvez le tableau TESTIMONIALS au début du fichier. Chaque ligne correspond à un client :

{ name: "Carlos Mendez", country: "México", initials: "CM", product: "TORVEXIA TX504", stars: 5 }, ← 4 ou 5 étoiles

Étape 2 — Texte et rôle traduits

Pour chaque langue, ajoutez l'avis dans le fichier correspondant à la même position dans le tableau testimonials.items :

// messages/fr.json — 13ème entrée pour un nouveau client { "text": "Excellent service, livraison rapide...", "role": "Agriculteur, Maroc" }
⚠️
Synchronisation obligatoire

Le nombre d'entrées dans TESTIMONIALS (fichier .tsx) doit correspondre au nombre d'objets dans testimonials.items dans chacun des 6 fichiers de langue. Si vous ajoutez un 13ème client, vous devez ajouter une 13ème entrée dans les 6 fichiers JSON.

9.2 — Modifier le nombre d'étoiles

Dans le tableau TESTIMONIALS, changez la valeur de stars de 5 à 4 (ou inversement). Les étoiles grises apparaissent automatiquement pour compléter jusqu'à 5.

9.3 — Supprimer un témoignage

Supprimez la ligne correspondante dans TESTIMONIALS ET supprimez l'objet correspondant (même position) dans les 6 fichiers JSON.

✅
Astuce crédibilité

Alternez 4 et 5 étoiles pour rendre les avis plus crédibles. Un mélange de 7×5⭐ et 5×4⭐ comme actuellement est optimal — trop de 5 étoiles peut sembler suspect.

10

Mettre en ligne — Déploiement

Publier votre site pour qu'il soit accessible depuis Internet

Pour mettre le site en ligne, la méthode recommandée est Vercel — la plateforme officielle de Next.js, gratuite pour les projets personnels et professionnels petits à moyens.

10.1 — Déployer sur Vercel (méthode recommandée)

Créez un compte sur vercel.com (gratuit, connexion avec GitHub recommandée).
Uploadez votre projet sur GitHub (ou GitLab) : créez un dépôt et poussez le code du dossier torvexia-global/.
Dans Vercel, cliquez "New Project" et sélectionnez votre dépôt GitHub.
Configurez les variables d'environnement (voir section 10.2 ci-dessous).
Cliquez "Deploy". Vercel construira et publiera automatiquement votre site.

10.2 — Variables d'environnement en production

Dans les paramètres Vercel de votre projet, ajoutez ces variables (onglet "Environment Variables") :

VariableValeurDescription
ADMIN_PASSWORDVotre mot de passe sécuriséMot de passe du panneau admin
🔒
Ne jamais uploader .env.local sur GitHub

Le fichier .env.local contient votre mot de passe. Il est déjà ignoré par Git (dans .gitignore). Saisissez toujours vos variables directement dans l'interface Vercel.

10.3 — Domaine personnalisé

Dans Vercel → votre projet → onglet "Domains", ajoutez votre domaine (ex : torvexia.com). Vercel vous donne les enregistrements DNS à configurer chez votre registrar (GoDaddy, OVH, Namecheap, etc.).

10.4 — Mises à jour du site

Chaque fois que vous modifiez des fichiers et les poussez sur GitHub, Vercel redéploiera automatiquement le site en quelques minutes.

📁
Important — Fichiers uploadés en production

Les fichiers uploadés via la Médiathèque sont stockés dans public/uploads/. En production sur Vercel (système de fichiers en lecture seule), les uploads ne seront pas persistants entre déploiements. Pour une solution durable, il faudra connecter un service de stockage cloud comme Cloudinary ou AWS S3.

Résolution des problèmes courants

Solutions aux situations les plus fréquentes

Le site ne démarre pas (npm run dev échoue)

SymptômeCause probableSolution
"Port 3000 already in use"Un autre serveur est déjà ouvertFermez l'autre terminal et relancez
Erreur de module manquantDépendances non installéesLancez npm install puis réessayez
Erreur JSON parseFichier de langue invalideVérifiez les fichiers messages/*.json sur jsonlint.com

Mot de passe oublié

Ouvrez le fichier .env.local à la racine du projet, lisez la ligne ADMIN_PASSWORD=... — c'est votre mot de passe actuel. Si vous l'avez perdu, remplacez-le par un nouveau mot de passe et redémarrez le serveur.

Les images uploadées ne s'affichent pas

SymptômeSolution
Image en blanc/gris dans la grilleL'upload a peut-être échoué. Vérifiez le dossier public/uploads/
Erreur "File too large"Le fichier dépasse 100 MB. Compressez-le avant d'uploader
Erreur "Unsupported file type"Format non supporté. Utilisez JPG, PNG, WebP, MP4, WebM

Texte affiché dans la mauvaise langue

Si un texte reste en espagnol ou en français même après changement de langue, c'est qu'il est encore codé en dur dans le composant. Vérifiez le composant correspondant et assurez-vous qu'il utilise useTranslations() et non du texte fixe.

L'admin redirige toujours vers login

Le cookie de session a expiré (durée : 7 jours). Reconnectez-vous simplement. Si le problème persiste, vérifiez que ADMIN_PASSWORD est bien défini dans .env.local.

Le changement de texte ne s'affiche pas

Assurez-vous d'avoir sauvegardé le fichier.
Rafraîchissez le navigateur (Ctrl+R ou F5).
Si toujours pas visible, videz le cache : Ctrl+Shift+R (rechargement forcé).
